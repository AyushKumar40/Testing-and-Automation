# UnQue CloudBook - Swag Labs QA Automation Assignment

This repository contains the QA deliverables for the Swag Labs (SauceDemo) testing assignment. It includes a comprehensive Test Plan, a detailed Bug Report, and automated UI test scripts written in JavaScript using Selenium WebDriver.

## Repository Structure

- `Test_Plan.md`: Scope, strategy, and manual test cases.
- `Bug_Report.md`: Documentation of 5 critical, non-obvious bugs found during exploratory testing.
- `tests/`: Directory containing the automated test scripts.
- `package.json`: Node dependencies.

## Prerequisites

To run the automated tests, you will need:

- Node.js (v14 or higher)
- npm (Node Package Manager)
- Google Chrome browser installed

## Installation

1. Clone this repository to your local machine.
2. Navigate to the project directory in your terminal.
3. Install the required dependencies by running:
   ```bash
   npm install
   ```
